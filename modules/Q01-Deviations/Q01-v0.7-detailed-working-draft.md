# Q01 v0.7 — Detailed working specification (not independently accepted)

## Logical inputs
Identity: deviation ID, site, source system. Event: description, occurrence/detection date, process. Classification: source and mapped classification, category. Investigation: status, findings, conclusion, closure date. Root cause/contributors. Conditional: affected batches/products, containment, scope expansion, disposition links, CAPA ID/implementation/effectiveness, related event IDs, due dates/extensions/reopenings. Optional or analysis-dependent: equipment, supplier, material, procedure, operating context. Missing required information means assessment unavailable, not favorable.

## KPI proposals
Deviation frequency = events / relevant process exposure. Major/Critical rate = events / relevant process exposure. On-time closure = investigations closed by applicable approved due date / investigations due in period. Overdue rate = open overdue / all open. Reopening = reopened / closed. Root cause adequacy = adequate / assessed. Impact adequacy = adequate / applicable assessed. CAPA effectiveness = verified effective / conclusively verified. Recurrence = confirmed recurring / assessed. Management timeliness = actions completed on time / due. Denominators and extension rules remain open Q01-OPEN-02. No double count from many-to-many CAPA/deviation links. Distinguish low event counts from low reporting.

## Recurrence
Candidate keyword/semantic search, then contextual failure mechanism, root cause, operational context, chronology and CAPA intent. Outcomes: confirmed, probable, possible, no recurrence identified. Support with source record IDs and reasoning. Similar keywords do not prove recurrence; different terms can share a mechanism. Related events after CAPA implementation prompt reassessment, not automatic reversal.

## Qualification
Deterministic calculations must pass approved cases; contextual judgments need representative expert-labeled evidence and pre-agreed performance criteria; forecasts require independent empirical qualification. No tests executed.
