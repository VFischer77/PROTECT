# GOV-001-05 — Release, Configuration & Change Control
**v0.1 DRAFT — approval pending**

## Baseline
Each release receives semantic version, commit/tag, approved requirement/design/risk baseline, dependency inventory, deployment configuration, test report, anomalies, known limitations, user guidance and release authorization.

## Change control
Record request and impact, affected modules/requirements, data migration and interfaces, risk, approvals, implementation, targeted tests, regression justification, rollout and rollback. Emergency fixes follow documented retrospective review.

## GO/NO-GO
GO only with approved intended use, verified requirements and risk controls, accepted V&V, managed unresolved issues, access/security review, reproducible artifact and authorized founder sign-off. Otherwise NO-GO. No agent may autonomously publish a commercial release.

## Maintenance
Support, incidents, vulnerability and dependency monitoring, CAPA where justified, backup/recovery for hosted deployment, customer communication and end-of-support policy. Deployment model remains TBD.
